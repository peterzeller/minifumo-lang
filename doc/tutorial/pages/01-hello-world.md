# 1. Hello world

A Minifumo program is usually organized around functions, and execution starts in `main`.

Comments begin with `//` and continue until the end of the line. This is useful for short explanations, expected output notes, and local reminders while learning the language.

The example below keeps things minimal: it defines a single `main` function that prints a string.
