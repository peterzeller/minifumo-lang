# 8. Type parameters

Type parameters make definitions reusable across many concrete types.

This section demonstrates both generic data and generic functions:

- a generic list type,
- `map` to transform element types,
- `foldl` to accumulate values.

These are core functional patterns; once comfortable with them, you can encode many common algorithms without duplicating code for each element type.
